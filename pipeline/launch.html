Mission Control · 2026-04-24

Four new pen pals need their voices, faces, and motion.

Code, manifests, and Scribbles' system prompt are already wired up. What's left is the taste work — picking voices, picking character images, picking storyboard beats, then generating videos. This is the playbook.

STEP 1

Generate voice samples

~30s · automated

Calls ElevenLabs TTS for each candidate voice in animals.json using that animal's greeting line. Output goes to pipeline/voice-samples/. Pre-generating saves clicks in the screener UI.

./pipeline/run.sh samples spider giraffe hippo eagle

Heads up

  • Skips files that already exist — safe to rerun.
  • Each animal has 2 stock voice candidates; you'll likely design a custom voice for at least Pip (squeaky child voice is hard to find off-the-shelf).
STEP 2

Pick or design voices

~10–15 min · taste

Launches the Voice Screener at localhost:8111. Listen to candidates, design custom voices from each animal's voiceDesignPrompt, save winners to your ElevenLabs library, then paste the chosen voiceId into src/data/animals.ts.

./pipeline/run.sh voices

    STEP 3

    Pick character images

    ~15 min · ~$0.32 in Imagen

    Launches the Character Picker at localhost:8222. Generates 4 candidates per animal from the editable imagePrompt. Pick a favorite → saves as {id}_character.png. This becomes the reference frame for video generation.

    ./pipeline/run.sh characters

    Visual direction (briefs are below)

    • Photorealistic — must read as wildlife photography, never illustrated/storybook.
    • Composition — animal facing camera, eyes visible, subtle expression. Will be the idle-loop "talking head".
    • Spider: the scariest one to get right. Push for "puppy-like jumping spider" — kid-safe, fuzzy, big shiny eyes. Reject anything web-y or creepy.
    • Hippo: half-submerged framing matters — eyes + nostrils above water, shows the silly grin.
    STEP 4

    Pick storyboard beats

    ~15 min

    Launches the Storyboard Picker at localhost:8444. Generates beat keyframes from the chosen character image (mail receiving, opening letter, reading, composing, sending). The video generator uses these as anchors so motion stays on-model.

    ./pipeline/run.sh storyboards

    Minimum required

    • At minimum, beat_1_receiving — same animal, same lighting, looking at an envelope arriving. This drives the receive video.
    • Idle video uses the character image directly, no extra beats needed.
    • Pig has all 5 beats — that was the most-polished test case; mirror it if you want a richer animation.
    STEP 5

    Generate videos

    ~10 min compute · variable cost

    Launches the Video Generator at localhost:8333. Produces {id}_idle.mp4 and {id}_receive.mp4 per animal, plus extracted .jpg posters. Output lands in pipeline/generated-videos/.

    ./pipeline/run.sh videos

    Quality bar

    • Idle: subtle breathing, blinking, micro-head-tilts. Should loop seamlessly — first and last frames near-identical.
    • Receive: reaction beat (looks up, eyes widen, slight smile) when the letter arrives. ~3–5s.
    • Reject any clip with morphing limbs, melted features, or obvious AI tells. Re-roll is cheaper than shipping.
    STEP 6

    Ship

    ~2 min · automated

    Single command: copies .mp4+.jpg into public/animal-videos/ and public/animal-thumbnails/, uploads them to Cloudflare R2 via wrangler, then runs scripts/generate-animal-pages.tsx to rebuild the SEO landing pages and sitemap.

    ./pipeline/run.sh ship spider giraffe hippo eagle

    Don't forget

    • After voice screener: paste real voiceId into src/data/animals.ts (currently placeholders).
    • Push Scribbles agent updates: /11labs push
    • Open a feature branch + PR for the Vercel preview before merging to master.

    PROMPTS

    Manual video generation prompts

    copy → Nano Banana / Veo / Kling with reference image

    Three variants per state per animal so you can A/B which read works best with the chosen character image. Drop the character image into your image-to-video tool as the seed, paste a prompt, render. When you've got winners, save as {id}_idle.mp4 and {id}_receive.mp4 in pipeline/generated-videos/, then ./pipeline/run.sh ship.

    The three variants

    • Idle / Stillness — minimal motion (breath + one blink). Safest for a clean loop.
    • Idle / Ambient — environmental life (breeze, water ripples, dewdrops shimmer) plus character breathing.
    • Idle / Personality — one signature gesture (web-touch, ear-flick, yawn, head-scan).
    • Receive / Soft notice — gentle eye-widen + small smile. Most "in character" for shy animals (Echo, Pip).
    • Receive / Joyful surprise — bigger reaction. Best for outgoing personalities (Hank, Gigi).
    • Receive / Curious tilt — head turns/tilts toward camera. Strong on-camera presence; works for any animal.

    Reading for image-to-video specifically

    • Each prompt opens with "This exact [animal] from the reference image" — keeps the i2v model anchored on identity.
    • Each prompt names what stays unchanged (lighting, coloring, background) so the model doesn't drift.
    • Each prompt locks the camera. Don't add camera-motion language — the still character image is your hero frame.
    • Reject any output where: limbs morph/melt, fur texture turns plasticky, environment shifts, or the animal looks at all unfriendly. Re-roll is cheaper than shipping.
